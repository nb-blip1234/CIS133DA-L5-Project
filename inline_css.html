Understanding Generic Font Families

CSS has five generic font families that act as a backup when a specific font is not available. Serif fonts, like Times New Roman, have small strokes (serifs) at the ends of the letters and look traditional, like a printed book. Sans-serif fonts, like Arial, do not have those strokes, so they look clean and modern and are easy to read on screens. Monospace fonts, like Courier New, give every character the same width, which makes them good for showing code. Cursive fonts imitate handwriting, and fantasy fonts are decorative and playful, so both are best used only for small amounts of text such as titles.

Ways to Indicate Color

There are several ways to set a color on a web page or in text. The simplest is a color name, such as red or darkgreen, but there are only about 140 named colors. A hexadecimal value, such as #1b4f72, uses a pound sign followed by six digits that set the amount of red, green, and blue. The RGB method, such as rgb(142, 68, 173), sets red, green, and blue with numbers from 0 to 255. You can also use RGBA to add transparency, or HSL to describe a color by its hue, saturation, and lightness.
